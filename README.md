# BrowCanvas 眉型設計板

美容老師用的眉型設計工具：上傳顧客正臉照，自動偵測五官、抹除原生眉、疊上新眉型，可多人同時看同一張設計。

## 上課網址

**https://nice923boss.github.io/BrowCanvas/**（GitHub Pages，老師與學員都開這個，不用開任何伺服器）

- 同步房間由網址決定：同一個網址就是同一個房間。要分班時用「邀請連結」產生 `?room=xxx`。
- HTTPS，手機可直接用相機拍照。
- 更新：改完程式 `git push`，GitHub Pages 約 1 分鐘後生效；瀏覽器最多快取 10 分鐘，上課中不要更新。

## 本機開發

雙擊 `start.bat`（需要 Python 3），開啟 `http://localhost:8790/`，並在視窗印出區網網址。本機與 GitHub Pages 是不同房間。

- 換埠：先設環境變數 `BROWCANVAS_PORT`，再執行 `start.bat`。
- 埠被占用時（通常是已經開著），會直接開瀏覽器後停在視窗等你按鍵。
- 關閉黑色視窗即停止伺服器。

純前端，無建置步驟。任何能正確送出 `.js` 為 `text/javascript` 的靜態伺服器都能跑。

## 主要功能

- 照片：上傳、拍照（需安全環境，見下方）、示範圖（`assets/demo-model.jpg`，ComfyUI 生成的 AI 模特兒）。
- 偵測：MediaPipe FaceLandmarker（478 點），在瀏覽器本機運算，照片不上傳。
- 圖層：照片透明度、人偶草圖（白底）、新眉型、調整控制點、臉型輪廓、眼睛、原生眉、耳朵（估計）、鼻子嘴巴、眉型定位線、三庭五眼。
- 抹除原生眉：自動遮罩 + 抹除筆／還原筆補修，可調抹除範圍、毛髮靈敏度、膚質紋理。
- 眉型：7 種預設眉型；左右分開調整位置、大小、旋轉、眉頭／眉峰／眉尾、粗細、弧度、濃淡；左右連動、鏡像、重設到定位線。
- 方案：多方案、設計理由、方案比較檢視與比較圖匯出。
- 匯出：圖片（含／不含參考線）、方案比較圖、專案檔（存檔與開啟）。
- 顧客紀錄、顧客留資／預約：存在這台裝置的 IndexedDB（資料庫名 `browcanvas`）。
- 教學引導：依步驟切換圖層並說明定位方式。

左右用「畫面左／畫面右」，面板同時標示對應的顧客左右。

## 多人同步與控制權

- 同一個網址開的第一個分頁是主機（負責轉送與復原紀錄），其他人加入後即時看到變更（含動畫過渡）。
- 預設只有「控制者」能編輯，其他人觀看。一開始控制者是主機。
- 任何人可按「申請控制」，控制者右上角「已連線」左邊會出現「X 申請控制」，點開按同意就交接；新的控制者負責同意下一個申請。
- 控制者離開座位沒人同意時，可按「要求接手」：控制者畫面跳出 30 秒倒數，沒按「不移轉」就把完整控制權交給要求的人；也可按「立即移交」。控制者按「不移轉」後 10 分鐘內不會再收到接手要求（一般的「申請控制」不受影響）。秒數在 `js/net.js` 的 `NET_TIMING.takeoverMs`、`takeoverCooldownMs` 調整。
- 控制者可改成「開放所有人編輯」。
- 控制者離線時控制權回到主機；主機離開後，剩下的人自動接手並保留目前狀態與控制者。
- 顧客留資會送到目前控制者的裝置保存。
- 「已連線」選單 →「邀請連結」產生 `?room=xxx` 連結給別人開。
- 連線透過 PeerJS 公用信令伺服器建立，畫面資料走 WebRTC 點對點。信令連不上時進入單人模式，功能照常但不同步。

## 手機、平板

- 直接開 GitHub Pages 網址即可，相機可用。
- 本機開發時同一個 Wi-Fi 可用 `start.bat` 印出的 `http://<電腦IP>:8790/`（不是 HTTPS，相機不能用，請改用「上傳照片」）。

## 測試

```bash
node --test "tests/*.test.mjs"
```

需 Node 18 以上。涵蓋幾何與眉型、抹除演算法、狀態 reducer、同步協定（用記憶體假傳輸層）。不含瀏覽器 UI 測試。

## 檔案結構

| 路徑 | 內容 |
|------|------|
| `index.html`、`css/app.css` | 介面 |
| `js/app.js` | 進入點，組合各模組 |
| `js/state.js` | 狀態與 op reducer（同步與復原的基礎） |
| `js/net.js`、`js/transport-peer.js` | 主持人選舉、op 轉送、復原歷史；PeerJS 傳輸層 |
| `js/face.js`、`js/brow.js`、`js/geom.js` | 五官特徵、定位線、眉型幾何 |
| `js/erase.js` | 原生眉抹除 |
| `js/render.js` | 繪圖 |
| `js/panels.js`、`js/sliders.js`、`js/pointer.js`、`js/session-ui.js` | 面板、滑桿、拖曳、連線介面 |
| `js/photo-io.js`、`js/exporter.js`、`js/records.js`、`js/store.js` | 照片讀取、匯出、顧客紀錄、IndexedDB |
| `serve.py`、`start.bat` | 本機伺服器 |
| `tests/` | node:test 測試 |
